PixelCalc v0.2.2 is a bug-fix debug build that keeps the calculator frame inside rounded phone screens.

Highlights:
- Tightens the outer calculator margin so square pixel borders sit safely within the display.
- Refreshes the launcher foreground geometry for a cleaner PixelPark icon shape.
- Keeps the standard and matrix calculator flows unchanged.

The attached APK is a debug build for testing and demo use.
